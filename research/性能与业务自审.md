# 极简状态 1.3：性能与业务自审

日期：2026-11-25。测试环境：单台 Apple Silicon、macOS 27.0.1、Swift 6.4。

## 结论

本机功能和异常边界检查通过，适合在已验证的本机条件下使用。**尚不能宣称达到商业发布标准**：没有完成多系统、多机型、睡眠唤醒、真实网络切换和 24–72 小时连续运行验证；应用使用本地签名，尚无 Developer ID 签名和苹果公证。

## 本轮实际修复

- 菜单栏改为固定 164pt，C/M 与百分比贴紧，网速短格式最多四字符；数据变化不再改变入口宽度。仅图标模式为 26pt。
- 首次采样和零 tick 差值正确处理，已有 CPU 读数不会无故变成空值。
- **修正进程 CPU 时间单位**：此设备 Mach timebase 为 41.66667；旧实现把原始计数直接当纳秒，会低估应用列表中的 CPU。新增与 getrusage 的独立对照。
- UI 状态用 MainActor 隔离，后台采样使用独立 actor，扫描和智能选择在后台任务执行。Swift 6 完整并发检查及零警告编译通过。
- 网络接口名称每次批量获取，使用 64 位流量计数，处理新接口、计数重置与零时间差。
- 文件检查重新读取最新元数据，避免 Foundation URL 缓存旧信息；确认对话框之后再次核对。文件、应用状态或启动项可执行程序变化时拒绝清理。
- 应用退出同时核对 PID 与启动时间，避免退出复用 PID 的新进程。
- 扫描有时间/数量上限，结果去重，每类展示最大的 100 个；树状列表按需加载，支持父子半选、分支全选和全选已展示项目。
- 智能选择只预选已退出浏览器的明确缓存和明确扩展名的旧日志。安装收据始终只读，残留配置、启动项、大文件和安装包不参与智能预选。
- 测试命令和预览逻辑仅编译进独立测试程序，不包含在发布应用中。构建目录自包含，便于源码迁移。

## 验证结果

自动检查记录中 37 个 PASS，未出现 FAIL；最后一轮审计通过。

采样性能：P50 0.087ms / P95 0.092ms；RSS Δ 0.11MB；平均 CPU 时间 0.087ms/次；线程 3→3；host refs 2→2

应用列表采样：P50 0.464ms / P95 0.479ms

实际应用进程连续观测 60.2 秒：平均 CPU 约 **0.88%（按单核口径）**；驻留内存 **106.1 → 99.7 MB**，峰值 106.1 MB；线程数 6–6，没有增长。此观测未严格控制用户是否展开面板，不能当成统一环境的空闲跑分。

连续 3000 次内核采样的 host 端口引用数保持不变，内存增长小于 1 MB。压力采样耗时很短，**不等同于长时间稳定性测试**。

已验证的业务边界：

- 0–100% 以及高低网速格式均适配固定入口；C/M 无内部补位空格。
- 新接口、重置接口、零时间差不会产生虚假高速或除零。
- 树状全选、半选、分支切换、类别过滤后选择范围及大小计算正确；安装记录不进入选择集合。
- 旧/新文件年龄规则、符号链接、目录范围、DMG/PKG 与 ZIP、大文件阈值、文件改写后的复核。
- 浏览器及辅助进程运行时不进行智能预选；未知缓存、非日志压缩包、配置、安装记录和启动项不预选。
- 启动项只将目标确实不存在的绝对路径条目标为候选；正常命令、相对命令和损坏 plist 均跳过；目标恢复后拒绝清理。
- 重复扫描根目录不会重复计数，数量和时间上限会停止并提示部分结果。
- 用自行创建的临时文件调用系统废纸篓 API，再恢复到原处，内容一致；测试文件和目录已清理。没有关闭用户实际应用或移动用户实际文件。

## 使用限制与后续发布验证

没有一种删除规则能保证「100% 不影响现在」。缓存可能影响后续启动速度，旧日志可能影响故障回溯，配置和大文件可能仍有用途。残留识别是启发式的，外置磁盘或非标准目录中的应用可能未被识别，因此只作为人工检查候选。

宏观内存与单进程驻留量的口径不同，共享页与压缩页会造成差别。文件逻辑体积不等于实际可释放物理空间；移到废纸篓后需要用户清倒才能释放其磁盘占用。无权限目录会跳过，扫描不是全磁盘覆盖。

商业发布前仍需：覆盖 macOS 13–27 和多种 Apple Silicon 设备、不同显示缩放和收纳工具；验证睡眠/唤醒、断网、Wi-Fi/有线/VPN切换；真实机器至少 24–72 小时运行观察；更多应用的保存提示/拒绝退出和受保护文件部分失败流程；开发者签名、公证与安装/升级流程验证。

macOS 没有 Windows 注册表。pkgutil 手册说明 --forget 只丢弃安装收据、不移除已安装文件，不能用它替代应用卸载或当成腾空间的一键清理。本工具列出安装记录供查看，不删除这些记录，也不重建 LaunchServices 数据库。
