# macOS 清理工具调研与本工具的扩展

查阅日期：2026-11-25。依据官方产品页、帮助文档和公开项目说明；没有安装这些产品做同一台机器的跑分，也没有独立证据证明某款是「世界最强」。不同工具的重点不同。

| 工具 | 公开资料中的侧重点 | 本工具借鉴的方向 |
|---|---|---|
| [CleanMyMac](https://macpaw.com/cleanmymac) | 系统/应用垃圾、卸载残留、大文件、重复和相似文件、维护与恶意软件检测 | 将扫描范围和文件类别分开，缓存不只在一个目录 |
| [DaisyDisk](https://daisydiskapp.com/) | 磁盘空间分析、定位大型文件和文件夹、显示隐藏占用 | 加入下载大文件候选，保留文件查看入口，不将「大」直接判成垃圾 |
| [OnyX](https://titanium-software.fr/en/onyx.html) | 系统维护、缓存清理、数据库和索引重建 | 区分维护任务与磁盘文件清理；本工具暂不执行索引重建等系统操作 |
| [Pearcleaner](https://github.com/alienator88/Pearcleaner) | 应用卸载、孤立文件搜索、开发环境管理、包含/排除目录 | 加入开发构建缓存和明确目录规则；卸载残留需要更完整的应用归属识别，尚未实现 |
| [腾讯柠檬](https://lemon.qq.com/) / [公开项目](https://github.com/Tencent/lemon-cleaner) | 微信、QQ、Xcode 等专项扫描，大文件、重复文件、相似照片、卸载、空间分析 | 补充沙盒缓存、浏览器缓存、日志和安装包；聊天附件不是普通缓存，不默认扫描 |

上述功能来自厂商/项目自身的说明；没有采用厂商宣传的「平均能清理多少 GB」来判断强弱。Pearcleaner 的公开 README 当时也说明开发暂缓，因此不能仅凭功能列表判断维护质量。

## 为什么原版扫得少

原版只有 `~/Library/Caches` 一个根目录，要求文件至少 14 天未修改、未访问，还会排除能识别的运行应用缓存，并只展示最大的 100 个文件。商业工具通常包含更多目录、专项规则、更多文件类别，也可能请求全磁盘权限；扫描出的体积不代表所有文件都适合删除。

## 已补充的明确规则

1. 用户缓存：`~/Library/Caches`。
2. 沙盒/应用组缓存：在 `~/Library/Containers` 和 `~/Library/Group Containers` 下，仅查找 `Data/Library/Caches`、`Library/Caches`、`Caches`。不扫描容器内的文稿、数据库、偏好设置。
3. 浏览器专项缓存：Chrome、Edge、Brave、Chromium 的 Default / Profile 目录下，仅扫描 Cache、Code Cache、GPUCache、DawnCache。明确排除历史记录、Cookies、密码数据库、Local Storage 和 IndexedDB。
4. 旧日志：`~/Library/Logs` 及沙盒的 `Data/Library/Logs` / `Library/Logs`。
5. Xcode 构建缓存：`~/Library/Developer/Xcode/DerivedData`；不扫描 Archives 或项目源文件。
6. 旧安装包：`~/Downloads` 内的普通 DMG / PKG 文件；不将 ZIP 压缩包直接判成安装包。
7. 下载大文件：下载目录内 100 MB 以上、至少 30 天未使用的普通文件，排除已经归类的 DMG / PKG。只列作候选，需用户确认价值。

缓存、日志、构建缓存、安装包默认至少 14 天未修改和未访问。「包含近期缓存」只取消应用缓存的年龄限制，其他类别保持原规则；仍排除可识别的运行应用。跳过符号链接、不可读取路径及非普通文件。清理前再次核对文件大小、修改时间及运行应用状态。

扫描有数量和时间上限，每类仅展示扫描范围内最大的 100 个候选，总候选量单独显示。不会暗中扩大到整个硬盘。

## 可进一步扩展，但本版尚未实现

卸载残留需要维护已安装应用索引和文件归属，避免把后台服务数据误判成孤立文件。重复文件需要按大小分组后计算内容摘要并保留一份；相似照片需要专门的相似度算法。微信专项需区分可重建缓存、附件和聊天数据库。磁盘快照、系统缓存和索引维护涉及不同权限和恢复方式，不能通过普通文件扫描替代。

## 额外核对的资料

- [MacPaw：缓存类别与清理说明](https://macpaw.com/how-to/clear-cache-on-mac)：区分用户、系统、浏览器缓存，指出浏览器缓存与历史、密码、Cookie 属于不同类别。
- [Apple：释放 Mac 上的存储空间](https://support.apple.com/zh-cn/102624)：下载文件、应用和大文件可按需要整理；文件移到废纸篓后，清倒废纸篓才真正释放其占用空间。

本工具的恢复机制是移到废纸篓后可放回，因此不自动清空废纸篓。内存释放通过正常退出所选应用实现，与删除磁盘缓存分开处理。
