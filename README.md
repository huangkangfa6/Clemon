# 极简状态 1.3

原生 macOS 菜单栏监控与清理工具。适用于 Apple Silicon（M1/M2/M3/M4 等）、macOS 13 或更新系统。顶部固定 164pt，默认显示 `C16% M77% ↑1.2M ↓97K`，每两秒刷新。

- C：CPU 整机利用率，范围 0–100%。
- M：已用运行内存的百分比；点击展开可看已用 GB 和总内存。
- ↑ / ↓：上传和下载速率。K = KB/s，M = MB/s，G = GB/s，按 1024 进制换算。

鼠标停留在菜单栏入口上可看中文解释。右上角「…」→「菜单栏显示」可选文字与数字、紧凑四项或仅小图标（26pt）。展开收纳箭头后，按住 Command 将入口拖到可见区域。应用记住系统的菜单栏位置；第三方收纳工具可能还有独立隐藏规则。

## 在新 Mac 上安装

解压 Apple Silicon 应用压缩包，将 `极简状态.app` 拖到「应用程序」文件夹，双击启动。入口在顶部菜单栏，没有 Dock 图标。不需要 Python、Xcode 或其他运行环境。

这份应用使用本地签名，尚未做 Developer ID 签名和苹果公证。新电脑可能显示「无法验证开发者」；对自己传过去的这份应用，可在「系统设置 → 隐私与安全性」按系统提示允许打开。

不默认设置开机启动。需要时可在「系统设置 → 通用 → 登录项」添加此应用。展开面板底部有「退出」按钮。

## 释放资源与清理

「释放内存 · 减轻 CPU」可按占用排序并正常退出所选应用；如有未保存内容，应用可能要求保存。退出前核对进程启动时间，避免 PID 复用时退出另一个进程。

清理页面支持类别 → 应用/文件夹 → 文件的树状展开、半选、分支全选和全选当前展示。每类最多展示扫描范围内最大的 100 个结果，最多 800 个；完整候选总量与展示数量分别统计。全选不会包括安装记录，也不会选择未展示的结果。

| 类别 | 扫描规则 |
|---|---|
| 应用缓存 | 用户缓存、沙盒和应用组缓存；Chrome / Edge / Brave / Chromium 的明确缓存目录 |
| 旧日志 | 用户和沙盒日志 |
| 构建缓存 | Xcode DerivedData，保留 Archives 和源文件 |
| 旧安装包 | 下载目录里的普通 DMG / PKG 文件，不将 ZIP 默认判为安装包 |
| 下载大文件 | 100MB 以上且至少 30 天未使用的普通下载文件 |
| 应用残留候选 | 标识明确、未找到对应已安装应用的第三方缓存和偏好设置；这是启发式候选，不保证对应应用已经卸载 |
| 失效启动项 | 用户 LaunchAgents 中至少 14 天未修改、命令为绝对路径且目标确实不存在的 plist；移除会改变登录启动设置 |
| 安装记录 | 系统 PKG 收据，仅查看，不可选择或清理 |

缓存、日志、构建缓存、安装包和残留默认要求至少 14 天未修改且未访问。勾选「包含近期缓存」后重新扫描，只扩大应用缓存范围。跳过符号链接和能识别的运行中应用缓存。扫描最多检查 150,000 项或运行 30 秒，每个扫描根目录最多 5 秒；达到限制或遇到无权限目录会提示。

「智能选择」只预选已退出浏览器的明确缓存和扩展名明确的旧日志，排除未知缓存、大文件、安装包、残留配置、启动项和安装记录。它是低风险推荐，不能保证删除后 100% 无影响。

选中后可以在 Finder 查看文件。确认前和确认后再次读取最新文件信息；大小、修改时间、应用状态或启动项目标变化时会跳过。清理只移到废纸篓，可放回；不清空废纸篓，清倒后才真正释放磁盘空间。逻辑文件大小不等于必然可释放的物理空间，例如 APFS 克隆、共享块和稀疏文件。

macOS 没有 Windows 注册表。安装收据、配置和启动项用途不同，不能当作同一种「注册表垃圾」。不扫描聊天数据库、个人文稿、浏览器密码、历史记录、Cookie、Local Storage 或 IndexedDB。

## 从源码构建

源码文件夹自包含，所需环境为 Apple Silicon Mac 和 Swift 6 编译器（例如 Xcode 16 或更新版本的命令行工具）。在源码文件夹中执行：

```sh
zsh build.sh
```

应用生成于 `dist/极简状态.app`，可拖到应用程序文件夹。

测试与自审：

```sh
zsh test.sh
```

测试会编译独立的 `.build/MiniStatusTests`，检查数值边界、网络重置、树状选择、智能选择、文件变化、启动项和只读安装记录，使用自己生成的临时文件验证废纸篓恢复，连续采样 3000 次，并渲染三张页面预览。不会关闭用户的实际应用或移动用户的实际文件。发布应用不包含测试命令。

## 数据与验证范围

内存扣除文件缓存和可清除页，包含压缩内存，接近活动监视器的已用内存口径。应用内存为可归属进程的驻留量，可能包含共享页，不能相加等于整机已用内存。应用 CPU 经 Mach 时间单位换算后归一到全部核心。

网络合计启用的 en* 物理接口（Wi-Fi / 以太网），包含局域网流量，不重复累计 VPN 虚拟接口。接口首次出现或计数重置时跳过该差值。

应用不含联网、遥测、下载或后台 shell 命令，不请求管理员权限或辅助功能权限；无全磁盘访问权限时受保护目录会跳过。已在单台 Apple Silicon / macOS 27.0.1 上测试；尚未完成旧系统、多机型、睡眠唤醒、网络切换和 24–72 小时连续运行测试，不能据此宣称达到商业发布标准。

调研与自审材料在 `research/` 中；本版没有实现重复文件、相似照片、全磁盘分析或系统数据库重建。
